# GenshinImpactVT

当前版本 **v1.3**（内部版本 1.3.0）。Windows 桌面攻略视频工作台，使用 Python 3.12、PySide6、pythonnet、Microsoft WebView2 WinForms 和 WebView2 Evergreen Runtime，不依赖原版 MaBao。

支持 B站 AI/CC 字幕、视频内透明字幕、左下角小窗观看、八向方向氛围光、官方纯播放器、视频快捷控制和本地收藏/历史。查看 [版本记录](CHANGELOG.md)、[本地发行目录](RELEASES.md) 和 [Git 仓库说明](GIT_WORKFLOW.md)。

## 同页浏览和卸载

点击 B站个人空间、视频卡片等链接时，网页请求打开的 HTTP(S) 新窗口会直接在当前浏览器中跳转，地址栏同步更新，也可以用前进/后退返回。

卸载便携版：进入 **设置 → 软件管理 → 卸载此版本…**，确认后软件退出并移除此版本和指向它的桌面快捷方式。也可以直接双击程序文件夹内的 **Uninstall.exe**。

默认保留收藏、历史、设置和登录资料；勾选清除个人资料会删除所有版本共用的 `%LOCALAPPDATA%\MaBaoNext`，执行前须退出其他版本。只删除发行清单中内容未被修改的程序文件，额外放入或自行修改的文件会保留；其他发行版本、源码和下载 ZIP 也会保留。卸载助手仅在卸载时运行，临时副本安排在 Windows 重启后清理。

## 环境和启动

需要 Windows x64、Python 3.12 x64、.NET Framework 4.8 和 [WebView2 Evergreen Runtime](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution)。在 PowerShell 中进入本目录：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup_webview2.py
.\.venv\Scripts\python.exe main.py
```

需要画面字幕识别时，安装可选 CPU 依赖（包含固定版本的本地模型）：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-ocr.txt
```

SDK 脚本从官方 NuGet 下载固定版本并验证 SHA-256；安装过程需要网络。首次启动打开自带的本地合成视频页面，可输入 HTTP(S) 地址浏览。Evergreen Runtime 或 SDK 缺失时，浏览器底部状态栏显示原因。

需要重新打包完整轻量便携版时，先安装 `requirements-dev.txt`，再依次运行下列命令。最后一个命令会生成卸载清单和 ZIP，不会覆盖已有发行目录；再次构建请换一个尚不存在的输出目录。

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --distpath .build/dist --workpath .build/work packaging/GenshinImpactVT-light.spec
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --distpath .build/uninstall-dist --workpath .build/uninstall-work packaging/GenshinImpactVT-uninstall.spec
.\.venv\Scripts\python.exe packaging/prepare_portable.py --dist .build/dist/GenshinImpactVT --helper .build/uninstall-dist/Uninstall.exe --output releases/v1.3
```

单独运行主程序的 PyInstaller spec 不包含卸载助手和清单，此时卸载按钮禁用。开发源码同样不提供自删除入口。

收藏和历史保存在 `%LOCALAPPDATA%\MaBaoNext\library.sqlite3`；应用设置在同目录 `settings.ini`，浏览器数据在 `browser-profile`。历史包含访问过的完整 URL；浏览器数据与收藏、历史分开保存。点击侧栏可浏览收藏和历史，双击打开、选择后删除。悬浮控制可前进、后退、刷新、设置置顶和恢复主窗口。正常退出后恢复窗口配置及上次网页。

## 字幕识别与方向提醒

1. 打开攻略视频，在软件自带的网页里正常登录 B站。B站会对部分 AI 字幕要求登录；无需向本工具提交或导出密码、Cookie。
2. 点击左侧 **字幕识别**，开启功能，保持 **轻量：B站平台字幕 + 网页字幕**。点击 **刷新字幕（登录后点击）**，正常刷新视频后自动检测平台提供的字幕。
3. 状态显示“已载入 N 条字幕，无本地推理”后，按视频时间读取字幕，并高亮方向。网页当前已显示的字幕也可以直接读取；无需开启 OCR。支持正常快进、回退和多分 P 字幕切换。
4. 点击 **显示方向浮窗**，拖动调整位置；高亮颜色在“设置”页修改。**最近识别文字** 用于检查当前字幕。
   当前字幕直接显示在视频画面底部，透明背景、白字描边，不另占面板，也不挡鼠标操作；可在字幕页关闭 **在视频内显示透明字幕**。关闭识别、切换视频/分 P 和定位时清掉旧句子；暂停时保留当前时间点字幕。若网页自身的字幕同时显示造成重叠，可关闭播放器自己的字幕显示。
5. 游戏时可点击 **打开官方纯播放器**，使用 B站官方外链播放页，减少完整网页的侧栏和推荐内容；需要完整功能时点击 **返回完整 B站网页**。纯播放器已适配 7/8 切分 P，仍受平台自身画质、访问与播放限制。

方向浮窗默认带圆形柔光：例如“东北”在右上区域显示一团蓝色光晕，“西南”在左下显示，支持八个方向。背景透明，没有圆形边框。淡入后默认保持 5 秒，再用 450 ms 淡出；新方向立即换位置。字幕空隙或不含方向的新句子不会提前清除光效，跳转定位、切换视频和关闭识别仍会立即清除旧提示。可在“设置”中关闭 **方向氛围光**，或调整颜色、强度、浮窗大小以及高亮保持时间（1～30 秒）。拖动浮窗仍可调整位置。

光效直接由 Qt 绘制，不增加模型或网络请求。仅淡入/淡出的短时间内运行动画，保持期间和没有提示时不持续重绘；窗口使用不主动获取键盘焦点的属性。真实游戏前台表现仍需实际试用。

已在提供的视频 `https://www.bilibili.com/video/BV1CMHQzsEJV/?p=3` 上用软件正常登录会话验证：平台提供 `ai-zh` 中文轨，载入 287 条字幕，按方向时间点跳转后浮窗响应；未启动 OCR，也未加载 RapidOCR、ONNX Runtime、OpenCV、NumPy。

这条路线只复用 B站已提供且当前会话有权访问的字幕。它不能强制平台为每一个没有字幕的视频生成字幕；未登录、没有字幕、网络失败分别提示，不会自动启动本地语音识别。字幕响应和时间轴仅保存在内存，不导出账号信息，不向其他服务上传音频。

字幕文件按分 P 加载一次，之后只进行时间查找。载入平台字幕后不截图；播放时每 300 ms 查询时间，暂停时每 700 ms 查询。透明字幕仅在文字变化或视频缩放/滚动/全屏事件时更新布局，没有新增定时采样。关闭识别停止时间轮询。轻量便携包不包含 OCR/语音模型，运行环境仍需要 WebView2，因此完整 B站网页、视频解码和浏览器本身仍有开销。

## 可选的画面 OCR

源码安装可选依赖后，可以手动选择 **高级：手动开启画面字幕 OCR**。此前的独立 OCR 测试包仍可单独使用。默认轻量模式不会自动回退到 OCR；轻量便携包隐藏 OCR 控件并排除相关依赖。

画面 OCR 默认识别视频下方，也可点击 **框选字幕区域**，在视频快照上拖出矩形并保存，区域按视频比例缩放。可用 **打开本地识别示例** 验证；示例不是实际攻略准确率的证明。

手动 OCR 使用独立进程、CPU 两个推理线程和两次一致观察，默认每秒约两次采样；空字幕清除提示，快进、回退和切换视频使旧任务失效。关闭识别或退出时释放工作进程。显示浮窗与识别开关独立，隐藏浮窗不会自动停止识别。

文字过小、花字、弹幕遮挡和错误框选会影响结果；可适当放大视频或缩小识别区域。程序不录音，不识别没有画面字幕的语音，不上传字幕或视频截图，也不在运行时自动下载模型。主窗口隐藏或最小化时暂停画面 OCR。方向解析使用保守规则，尚不能理解所有口语和复杂路线。

模型来源、版本、校验值及许可见 [OCR 依赖说明](THIRD_PARTY_OCR.md)。

## 攻略视频辅助

双击 `GenshinImpactVT.lnk` 无控制台启动；也可以双击 `launch.vbs`。这些入口每次通过 Windows UAC 请求管理员权限，确认后以 pythonw 启动；取消时不会启动。命令行直接执行 `main.py` 沿用当前终端权限。启动异常会显示错误窗口。

v1.3 默认快捷键如下，均可在 **设置 → 自定义快捷键 → 编辑快捷键** 修改。编辑期间暂停键盘和侧键动作，修改后点击 **保存并启用**；支持单键或组合键，留空可禁用动作。重复键会被拒绝，系统保留键不允许使用。设置和侧键映射会在重启后恢复。

| 动作 | 默认按键 |
| --- | --- |
| 播放 / 暂停 | 鼠标侧键上键（XBUTTON2），键盘默认留空 |
| 快退 5 秒 | 5；鼠标侧键下键（XBUTTON1） |
| 快进 5 秒 | 6 |
| 上一集 / 下一集 | 7 / 8 |
| 显示 / 隐藏悬浮控制条 | F9 |
| 切换极简模式 | 0 |
| 显示 / 隐藏主窗口 | 9 |
| 最大化 / 还原 | F10 |
| 恢复正常界面 | F11 |
| 显示 / 隐藏方向浮窗 | F8 |

鼠标上、下侧键也可分别指定上表任一动作或禁用。全局快捷键在其他程序前台时也会触发；普通监听同时保留按键的原有功能，打字时也可能触发。可用“启用全局键盘快捷键”和“启用鼠标侧键”分别关闭。系统全局热键模式会占用所设键，注册冲突时显示具体失败项；编辑或退出时释放注册。游戏中的效果依赖权限和实际输入环境，便携版继续使用管理员权限启动。

点击 **小窗观看**：切换为 480×300 左下角窗口，隐藏导航、地址和底部栏，可继续缩到 320×180。控制条不会自动挡住视频；按 **F9** 或单击系统托盘图标显示/收起。控制条的 **收起** 和右上角关闭按钮只隐藏控制条，不退出视频；唤出不主动抢键盘焦点。位置会保存，换屏时限制在可见范围内。

找不到设置时，按 **F11**；也可右键托盘图标选择 **恢复正常界面**，或右键主窗口标题栏选择同名菜单。恢复后展开导航并调整到可用大小。更改过快捷键时以设置为准，托盘和标题栏入口不受快捷键配置影响。关闭主窗口仍会退出整个软件，也可使用托盘“退出软件”。

透明字幕在小窗和网页全屏下继续显示。HTML 全屏自动隐藏工具栏，退出后恢复此前状态；部分网站的网页内全屏不一定发出该事件。普通标题栏和网页自身控件可能仍然存在。

设置页可开启透明方向文字浮窗、拖动位置并选择高亮颜色。字幕识别页同时支持当前网页字幕和视频硬字幕 OCR，方向提示默认保持 5 秒，可在设置中调整到 1～30 秒；规则可能误判，复杂句子仍应以原视频为准。实际 B 站页面字幕结构和分集控件会变化，上一集/下一集不保证在所有视频可用。

浏览器底部“显示方向浮窗”按钮会在主窗口附近显示方向文字，可以拖到游戏小地图处；设置页可以关闭浮窗或修改高亮颜色。鼠标侧键默认启用：上键（Windows XBUTTON2，通常是前进键）播放/暂停，下键（XBUTTON1，通常是后退键）快退 5 秒，可以在设置页关闭。此功能不拦截侧键，当前应用或游戏仍可能同时处理原按键；部分驱动、游戏输入方式或不同权限级别可能影响监听。关闭 GenshinImpactVT 后监听自动移除。

窗口置顶默认开启，可在浏览器底部或悬浮控制中切换；已保存的用户选择优先。无边框游戏窗口通常可与桌面置顶窗口共存，但无法保证覆盖其他同样置顶的窗口或独占全屏画面。设置页的侧键状态会显示最近一次检测到的侧键；如果驱动报告的是模拟输入，可选择允许此类输入。

侧键监听可选择“后台原始输入”或“普通侧键监听”，两者不会同时启用，避免一次按键重复触发。原始输入使用 Windows Raw Input 的后台接收功能，只处理鼠标侧键，不抑制游戏输入；鼠标驱动将侧键改映射为键盘时可能无法收到原始侧键。接收模拟输入选项仅用于普通侧键监听；如某一种方式不可用，可在设置中切换并观察侧键状态。状态包含本次运行中的检测计数，便于比较切换前台程序之前和之后是否收到输入；计数不写入磁盘。
