# GenshinImpactVT

当前版本 **v1**（内部版本 1.0.0）。Windows 桌面攻略视频工作台，使用 Python 3.12、PySide6、pythonnet、Microsoft WebView2 WinForms 和 WebView2 Evergreen Runtime，不依赖原版 MaBao。

支持 B站 AI/CC 字幕、浏览器底部实时字幕、八向方向氛围光、官方纯播放器、视频快捷控制和本地收藏/历史。查看 [版本记录](CHANGELOG.md)、[本地发行目录](RELEASES.md) 和 [Git 仓库说明](GIT_WORKFLOW.md)。

## 环境和启动

需要 Windows x64、Python 3.12 x64、.NET Framework 4.8 和 [WebView2 Evergreen Runtime](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution)。在 PowerShell 中进入本目录：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup_webview2.py
.\.venv\Scripts\python.exe main.py
```

需要画面字幕识别时，安装可选 CPU 依赖（包含固定版本的本地模型）：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-ocr.txt
```

SDK 脚本从官方 NuGet 下载固定版本并验证 SHA-256；安装过程需要网络。首次启动打开自带的本地合成视频页面，可输入 HTTP(S) 地址浏览。Evergreen Runtime 或 SDK 缺失时，浏览器底部状态栏显示原因。

收藏和历史保存在 `%LOCALAPPDATA%\MaBaoNext\library.sqlite3`；应用设置在同目录 `settings.ini`，浏览器数据在 `browser-profile`。历史包含访问过的完整 URL；浏览器数据与收藏、历史分开保存。点击侧栏可浏览收藏和历史，双击打开、选择后删除。悬浮控制可前进、后退、刷新、设置置顶和恢复主窗口。正常退出后恢复窗口配置及上次网页。

## 检查

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -B tests\gui_smoke.py
.\.venv\Scripts\python.exe -B tests\video_smoke.py
```

GUI 测试需要交互式桌面，会打开窗口并模拟按键；仅使用临时本地 HTTP 服务和内置视频。测试数据位于被忽略的 `.test-data`、`.test-video`，不使用正式配置。

默认采用轻量字幕模式，复用 B站已生成的 AI/CC 字幕或网页当前显示字幕，不启动本地识别模型。没有本地语音转字幕、AI 导航、账号或同步服务；网站的正常登录由 WebView2 浏览器处理。参见 [测试记录](TESTING.md)。

## 字幕识别与方向提醒

1. 打开攻略视频，在软件自带的网页里正常登录 B站。B站会对部分 AI 字幕要求登录；无需向本工具提交或导出密码、Cookie。
2. 点击左侧 **字幕识别**，开启功能，保持 **轻量：B站平台字幕 + 网页字幕**。点击 **刷新字幕（登录后点击）**，正常刷新视频后自动检测平台提供的字幕。
3. 状态显示“已载入 N 条字幕，无本地推理”后，按视频时间读取字幕，并高亮方向。网页当前已显示的字幕也可以直接读取；无需开启 OCR。支持正常快进、回退和多分 P 字幕切换。
4. 点击 **显示方向浮窗**，拖动调整位置；高亮颜色在“设置”页修改。**最近识别文字** 用于检查当前字幕。
   当前字幕同时实时显示在浏览器底部，精简模式也可保留；可在字幕页关闭 **在浏览器底部显示当前字幕**。关闭识别、切换视频/分 P 和定位时清掉旧句子；暂停时保留当前时间点字幕。
5. 游戏时可点击 **打开官方纯播放器**，使用 B站官方外链播放页，减少完整网页的侧栏和推荐内容；需要完整功能时点击 **返回完整 B站网页**。纯播放器已适配 7/8 切分 P，仍受平台自身画质、访问与播放限制。

方向浮窗默认带圆形柔光：例如“东北”在右上区域显示一团蓝色光晕，“西南”在左下显示，支持八个方向。背景透明，没有圆形边框。短暂淡入后保持，再淡出；新方向立即换位置，快进/空字幕等清理动作立即取消旧光效。可在“设置”中关闭 **方向氛围光**，或调整颜色、强度、浮窗大小。拖动浮窗仍可调整位置。

光效直接由 Qt 绘制，不增加模型或网络请求。仅淡入/淡出的短时间内运行动画，保持期间和没有提示时不持续重绘；窗口使用不主动获取键盘焦点的属性。真实游戏前台表现仍需实际试用。

已在提供的视频 `https://www.bilibili.com/video/BV1CMHQzsEJV/?p=3` 上用软件正常登录会话验证：平台提供 `ai-zh` 中文轨，载入 287 条字幕，按方向时间点跳转后浮窗响应；未启动 OCR，也未加载 RapidOCR、ONNX Runtime、OpenCV、NumPy。

这条路线只复用 B站已提供且当前会话有权访问的字幕。它不能强制平台为每一个没有字幕的视频生成字幕；未登录、没有字幕、网络失败分别提示，不会自动启动本地语音识别。字幕响应和时间轴仅保存在内存，不导出账号信息，不向其他服务上传音频。

字幕文件按分 P 加载一次，之后只进行时间查找。载入平台字幕后不截图、不读取页面样式布局；播放时每 300 ms 查询，暂停时每 700 ms 查询，关闭功能停止轮询。轻量便携包不包含 OCR/语音模型，运行环境仍需要 WebView2，因此完整 B站网页、视频解码和浏览器本身仍有开销。

## 可选的画面 OCR

源码安装可选依赖后，可以手动选择 **高级：手动开启画面字幕 OCR**。此前的独立 OCR 测试包仍可单独使用。默认轻量模式不会自动回退到 OCR；轻量便携包隐藏 OCR 控件并排除相关依赖。

画面 OCR 默认识别视频下方，也可点击 **框选字幕区域**，在视频快照上拖出矩形并保存，区域按视频比例缩放。可用 **打开本地识别示例** 验证；示例不是实际攻略准确率的证明。

手动 OCR 使用独立进程、CPU 两个推理线程和两次一致观察，默认每秒约两次采样；空字幕清除提示，快进、回退和切换视频使旧任务失效。关闭识别或退出时释放工作进程。显示浮窗与识别开关独立，隐藏浮窗不会自动停止识别。

文字过小、花字、弹幕遮挡和错误框选会影响结果；可适当放大视频或缩小识别区域。程序不录音，不识别没有画面字幕的语音，不上传字幕或视频截图，也不在运行时自动下载模型。主窗口隐藏或最小化时暂停画面 OCR。方向解析使用保守规则，尚不能理解所有口语和复杂路线。

模型来源、版本、校验值及许可见 [OCR 依赖说明](THIRD_PARTY_OCR.md)。

## 攻略视频辅助

双击 `GenshinImpactVT.lnk` 无控制台启动；也可以双击 `launch.vbs`。这些入口每次通过 Windows UAC 请求管理员权限，确认后以 pythonw 启动；取消时不会启动。命令行直接执行 `main.py` 沿用当前终端权限。启动异常会显示错误窗口。

键盘视频快捷键只有 `7` 上一集和 `8` 下一集。侧键负责播放/暂停与快退。默认的普通监听不会拦截 7、8，当前游戏或其他程序也会收到原按键；在其他程序输入 7 或 8 时也可能切换视频，可在设置页关闭此功能。精简窗口隐藏应用导航、地址和底部栏；使用自动出现的悬浮控制中的“显示 / 隐藏工具栏”恢复。网页自己的控件和普通窗口标题栏可能仍然存在。网页报告 HTML 全屏时会尝试同步精简状态，部分网站的网页内全屏不一定发出该事件。

设置页可将 `7` / `8` 由普通监听切换为“系统全局热键”：Windows 会将两键注册为全局快捷键，可能使其他程序无法正常输入 7、8，适合需要时临时尝试；切回普通监听、关闭开关或退出软件会释放按键。注册失败时设置页显示提示。该方式不保证在游戏前台可用，也不影响鼠标侧键监听。

设置页可开启透明方向文字浮窗、拖动位置并选择高亮颜色。字幕识别页同时支持当前网页字幕和视频硬字幕 OCR，方向字高亮 2.5 秒；规则可能误判，复杂句子仍应以原视频为准。实际 B 站页面字幕结构和分集控件会变化，上一集/下一集不保证在所有视频可用。

浏览器底部“显示方向浮窗”按钮会在主窗口附近显示方向文字，可以拖到游戏小地图处；设置页可以关闭浮窗或修改高亮颜色。鼠标侧键默认启用：上键（Windows XBUTTON2，通常是前进键）播放/暂停，下键（XBUTTON1，通常是后退键）快退 5 秒，可以在设置页关闭。此功能不拦截侧键，当前应用或游戏仍可能同时处理原按键；部分驱动、游戏输入方式或不同权限级别可能影响监听。关闭 GenshinImpactVT 后监听自动移除。

窗口置顶默认开启，可在浏览器底部或悬浮控制中切换；已保存的用户选择优先。无边框游戏窗口通常可与桌面置顶窗口共存，但无法保证覆盖其他同样置顶的窗口或独占全屏画面。设置页的侧键状态会显示最近一次检测到的侧键；如果驱动报告的是模拟输入，可选择允许此类输入。

侧键监听可选择“后台原始输入”或“普通侧键监听”，两者不会同时启用，避免一次按键重复触发。原始输入使用 Windows Raw Input 的后台接收功能，只处理鼠标侧键，不抑制游戏输入；鼠标驱动将侧键改映射为键盘时可能无法收到原始侧键。接收模拟输入选项仅用于普通侧键监听；如某一种方式不可用，可在设置中切换并观察侧键状态。状态包含本次运行中的检测计数，便于比较切换前台程序之前和之后是否收到输入；计数不写入磁盘。
