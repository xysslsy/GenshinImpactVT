# GenshinImpactVT 使用说明

当前版本：**v2.0.1**。这是一个边玩原神、边看 B站攻略视频的小窗工具，不需要安装 Python。

## 怎么打开

1. 把 ZIP **全部解压**到你准备长期存放的文件夹，不要在压缩包里直接运行。
2. 打开 `GenshinImpactVT` 文件夹，双击 `GenshinImpactVT.exe`。不要单独移动 EXE，旁边的 `_internal` 目录必须保留。
3. Windows 询问管理员权限时选择“是”。这用于让全局按键与以管理员权限运行的游戏正常协作；取消就不会启动。
4. 如果提示缺少 WebView2，请从 [微软官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/#download) 安装 Evergreen Runtime，再打开软件。

支持 Windows 10/11 x64，需要系统具备 .NET Framework 4.8。包里没有原版 MaBao，也没有本地 AI 模型。

## 怎么边玩边看

1. 在地址栏粘贴 B站攻略视频网址并打开。需要登录时，在网页里正常登录 B站即可。
2. 点击底部的 **小窗观看**：窗口会放到屏幕左下角，并收起导航栏和工具栏。拖动边缘可以继续调整大小。
3. 打开 **窗口置顶**；游戏使用无边框窗口或窗口化全屏。独占全屏可能遮住普通桌面窗口。
4. 按 **F9** 显示/隐藏控制条，或单击屏幕右下角的系统托盘图标（可能在向上箭头里）。点控制条的 **收起** 或右上角关闭只会隐藏它，视频继续播放。
5. 按 **F11** 恢复完整界面。也可右键托盘图标或软件标题栏，选择 **恢复正常界面**，就能看到设置。
6. 侧键上键播放/暂停，下键回退 5 秒；键盘 **5** 回退 5 秒、**6** 快进 5 秒、**7** 上一集、**8** 下一集。

透明度快捷键：**F2** 更透明、**F3** 更不透明、**F4** 恢复完全不透明。每次调整 10%，范围为 20%～100%，会记住上次设置；设置页也可拖动滑块。视频画面一起透明，控制条保持清晰。托盘菜单也能恢复不透明。

其他默认键：**0** 切换极简模式、**9** 显示/隐藏主窗口、**F8** 显示/隐藏方向浮窗、**F10** 最大化/还原。

如果旧版自定义键与新增默认键冲突，会保留旧设置并将冲突的新动作留空，请手动分配。

所有上述按键和两个侧键的动作，都能在 **设置 → 自定义快捷键 → 编辑快捷键** 修改；点 **保存并启用** 生效并记住。留空可禁用，重复设置会提示冲突，点取消恢复原设置。编辑期间快捷键暂停。也可以整体关闭键盘或侧键监听。

这些是全局按键，打字或游戏时也可能触发。普通监听保留原按键功能，系统全局模式会占用设定的键；若提示被占用，请换键或换回普通监听。

## 怎么显示字幕和方向

1. 恢复工具栏，进入左侧 **字幕识别**。
2. 打开 **启用字幕识别与方向提醒**，选择 **自动：校验当前视频的 B站中文字幕**。
3. 现在默认启动就开启自动模式；打开新视频或切分 P 也会自动启用，即使之前选了手动模式。每轮失败最多串行尝试 3 次，成功即停止。状态显示“已核对 BV… · P… · 中文 · N 条字幕”后即可使用；视频号和分 P 应与正在播放的内容一致。
4. 仍未载入时可点 **重新自动读取字幕（不刷新视频）**，会先切回自动模式并开启识别，不会重载网页或把视频跳回开头。若想长期使用手动模式，取消“启动及新视频自动启用自动模式”即可。若提示登录失效、平台未提供字幕，请在软件内正常登录或检查该视频的字幕选项。
5. 勾选 **在视频内显示透明字幕**。字幕直接叠在视频画面底部，透明背景，不另占一块面板。
6. 点击 **显示方向浮窗**，拖到游戏小地图附近；识别到东北等方向时，对应的圆周边缘区域亮起柔光带：北方亮上弧，东北亮右上弧，中心保持透明，不再是一个光球。默认保持 5 秒，字幕短暂停顿不会立刻熄灭；设置里可改成 1～30 秒，也能调颜色、强度和大小。新方向会直接切换，跳转和切换视频会清掉旧方向。v2.0 会补捉两次查询之间的短方向句，重复方向也能再次点亮；同一句内多个顺序方向按文字比例近似推进，并非精确到每个语音词。

若网页自己的字幕也在显示造成重叠，可关闭播放器自己的字幕显示。小窗和网页全屏下，工具字幕都会继续显示。

软件只使用平台已提供、当前会话可以正常访问的字幕，不能保证每个视频都有；不会在后台录音或自动运行本地语音识别。没有字幕时，视频和快捷控制仍可正常使用。

## 更新、备份和退出

- 关闭旧版后，再从新文件夹打开新版。可右键 EXE 创建桌面快捷方式。
- 收藏、历史、设置和网页登录资料保存在 `%LOCALAPPDATA%\MaBaoNext`，与程序文件夹分开；更新程序不会主动删除这些资料。
- 备份个人资料前先正常退出软件；不要把个人资料目录发到 GitHub。
- 点击主窗口右上角关闭即可正常退出并保存配置。

## 网页跳转和卸载

点击网页里的个人空间、视频卡片等链接，会直接在当前窗口打开，不再额外弹出一个浏览器窗口。可以用前进/后退返回。

卸载有两个入口：**设置 → 软件管理 → 卸载此版本…**，或直接双击程序文件夹里的 **Uninstall.exe**。确认后软件会退出，删除此版本及其桌面快捷方式；其他版本、源码和下载 ZIP 保留。

默认保留个人资料。如果勾选删除收藏、历史、设置和登录资料，所有版本共用的这些资料都会清除，请先退出其他版本。自行添加或修改的文件会保留，因此卸载后文件夹可能仍在。卸载时使用的小型临时助手会在 Windows 重启后清理；正常使用时没有后台卸载服务。
