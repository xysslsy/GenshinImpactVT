# GenshinImpactVT 使用说明

这是一个边玩原神、边看 B站攻略视频的小窗工具，不需要安装 Python。

## 怎么打开

1. 把 ZIP **全部解压**到你准备长期存放的文件夹，不要在压缩包里直接运行。
2. 打开 `GenshinImpactVT` 文件夹，双击 `GenshinImpactVT.exe`。不要单独移动 EXE，旁边的 `_internal` 目录必须保留。
3. Windows 询问管理员权限时选择“是”。这用于让全局按键与以管理员权限运行的游戏正常协作；取消就不会启动。
4. 如果提示缺少 WebView2，请从 [微软官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/#download) 安装 Evergreen Runtime，再打开软件。

支持 Windows 10/11 x64，需要系统具备 .NET Framework 4.8。包里没有原版 MaBao，也没有本地 AI 模型。

## 怎么边玩边看

1. 在地址栏粘贴 B站攻略视频网址并打开。需要登录时，在网页里正常登录 B站即可。
2. 点击底部的 **小窗观看**：窗口会放到屏幕左下角，并收起导航栏和工具栏。拖动边缘可以继续调整大小。
3. 打开 **窗口置顶**；游戏使用无边框窗口或窗口化全屏。独占全屏可能遮住普通桌面窗口。
4. 若想恢复完整界面，在独立悬浮控制条点击 **显示 / 隐藏工具栏**。
5. 侧键上键播放/暂停，下键回退 5 秒；键盘 **7** 上一集、**8** 下一集。设置页可以关闭监听。普通监听不拦截按键，游戏也可能收到这些按键；在其他程序打字时按 7/8 也可能切集。

## 怎么显示字幕和方向

1. 恢复工具栏，进入左侧 **字幕识别**。
2. 打开 **启用字幕识别与方向提醒**，选择 **轻量：B站平台字幕 + 网页字幕**。
3. 登录后若未读到字幕，点击 **刷新字幕（登录后点击）**。状态显示“已载入 N 条字幕”后即可使用。
4. 勾选 **在视频内显示透明字幕**。字幕直接叠在视频画面底部，透明背景，不另占一块面板。
5. 点击 **显示方向浮窗**，拖到游戏小地图附近；识别到东北等方向时，对应区域亮起柔光。颜色、强度和大小在设置里调整。

若网页自己的字幕也在显示造成重叠，可关闭播放器自己的字幕显示。小窗和网页全屏下，工具字幕都会继续显示。

软件只使用平台已提供、当前会话可以正常访问的字幕，不能保证每个视频都有；不会在后台录音或自动运行本地语音识别。没有字幕时，视频和快捷控制仍可正常使用。

## 更新、备份和退出

- 关闭旧版后，再从新文件夹打开新版。可右键 EXE 创建桌面快捷方式。
- 收藏、历史、设置和网页登录资料保存在 `%LOCALAPPDATA%\MaBaoNext`，与程序文件夹分开；更新程序不会主动删除这些资料。
- 备份个人资料前先正常退出软件；不要把个人资料目录发到 GitHub。
- 点击主窗口右上角关闭即可正常退出并保存配置。

## 网页跳转和卸载

点击网页里的个人空间、视频卡片等链接，会直接在当前窗口打开，不再额外弹出一个浏览器窗口。可以用前进/后退返回。

卸载有两个入口：**设置 → 软件管理 → 卸载此版本…**，或直接双击程序文件夹里的 **Uninstall.exe**。确认后软件会退出，删除此版本及其桌面快捷方式；其他版本、源码和下载 ZIP 保留。

默认保留个人资料。如果勾选删除收藏、历史、设置和登录资料，所有版本共用的这些资料都会清除，请先退出其他版本。自行添加或修改的文件会保留，因此卸载后文件夹可能仍在。卸载时使用的小型临时助手会在 Windows 重启后清理；正常使用时没有后台卸载服务。
